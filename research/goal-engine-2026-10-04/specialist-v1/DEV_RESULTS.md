## Model

- Shipped: weighted logistic regression over 50 per-block features (position and message recency, block kind and tool group, BM25 vs goal and vs the last 3 text turns, identifier/path overlap with goal and recent turns, later references, duplicates, re-reads, error/git/code markers, goal shape, and LCC's own mechanical overlap + protection flags), size penalty alpha 0.5 (score = logit - alpha x log chars). Target: USED or goal-shared (`lrg`). Dev pick: {"arm": "lrg", "alpha": 0.5, "recall": 0.8836, "all_kept": 0.4344, "ev_cov": 0.947}.
- Alternative: GBDT depth 4, 350 trees, alpha 0.5; dev pick {"arm": "d4", "trees": 350, "alpha": 0.5, "recall": 0.8885, "all_kept": 0.4395, "ev_cov": 0.9506}.
- Selection rule: refit with the frozen recipe (no selection); per family: max dev recall AUC + 0.25 x all-kept AUC; LR ships. Dev at the chosen config per family (lr / lrg = LR on USED / USED-or-goal-shared; d4 / d4g / gbdt = GBDT depth 4): gbdt recall 0.8885 all-kept 0.4395 (alpha 0.5); lr recall 0.8836 all-kept 0.4344 (alpha 0.5). Depth 6 was tried in an earlier feature set and was no better than depth 4 and slower to train.
- Training rows / items: {"train": {"rows": 513352, "items": 1790, "excluded": {"no_agent_action": 71, "jev_overlap_group_or_fork": 255, "quarantined_dev_fork": 252, "no_used_candidate": 144}}, "dev": {"rows": 144094, "items": 353, "excluded": {"no_agent_action": 8}}}. Train excludes items forked from dev (label-v2 quarantine) and the jev-overlap lineage groups and their forks; negatives subsampled at 25% and re-weighted; every item weighs the same.
- No embedding feature (option b not taken): the only <= 30M-parameter model in the local HF cache is the MiniLM-L6 cross-encoder (22M, safetensors only, no ONNX export; onnxruntime is not in the LCC venv). Running it needs torch + transformers, whose import alone measured 235 MB peak RSS here before loading 87 MB of weights, so it cannot fit the 300 MB budget, and it would score ~400 goal-block pairs per item. No downloads allowed.

## Limits

- Labels are rule-based next-action evidence (v2 relabel), not human judgement; they lean recent.
- Dev was used for model selection (depth, trees, alpha): the dev numbers of the chosen model are optimistic. The frozen test split is the honest check and has not been run.
- jev-overlap has few items; Jev scores are saved v0.1 runs (no new remote calls).
- The edge suite is synthetic and single-author gold; v2 never trained on it.
- Latency measured on a shared, heavily loaded machine; treat it as an upper bound.
